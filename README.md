# DEM-KG

[Open DEM-KG](https://faisal-1921.github.io/DEM-KG/)

Published by ECE, The University of Hong Kong & EILAB, Tsinghua University. Building a unified knowledge structure for DEM market design.

A rule knowledge graph with 338 current nodes, 477 S bundles, 525 visible rule slices and 201 clusters. Scientific definitions, mathematics, conditions and citations are accessible inline.

The graph opens at 100% scale. Select a market template to highlight its nodes and internal edges; template and detail selection preserve the current scale and position. Click a highlighted node to focus its incoming and outgoing edges and their endpoints. Other elements become gray, noninteractive context. Click a neighbor to move focus; select the template again to restore the full template. Fit view is available as an explicit action. Rule-Chain and Rule-Cluster slices keep the full gray graph as noninteractive context.

No download controls or standalone Sources browser. Original Source documents, complete graph exports, translation maps and private audit records are excluded. Web code and browser-visible content remain copyable.
